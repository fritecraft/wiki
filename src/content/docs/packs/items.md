## Description
Le serveur propose un pack de ressources contenant énormément de textures d'items.
Ces textures ne remplacent pas les textures de base ! Grâce au mod Optifine, il est possible de "créer" des nouveaux items, avec une fonction de règles. L'apparence des items est en fait liée à leur nom.
Par exemple, la majorité des textures pour épée utilisent en fait l'item de base minecraft:diamond_sword, mais grâce à une règle d'expression régulière, il est possible de forcer le jeu à utiliser une autre texture.
  Note : il n'est pas possible pour les joueurs d'appliquer une texture soit-même via l'enclume, car des caractères cachés et inutilisables via l'enclume sont utilisés dans les règles.

## Problèmes de téléchargement
Le pack est proposé aux joueurs à la connexion du serveur. Il est donc nécessaire de bien avoir l'option "télécharger automatiquement" ou "demander", afin d'obtenir le pack. Le pack étant souvent mis à jour, il n'est pas disponnible à télécharger depuis le site, puisque cela obligerai les joueurs à manuellement le mettre à jour à chaque évolution.
Il arrive parfois que le téléchargement automatique ne fonctionne pas pour quelques joueurs.
Voici des pistes d'études afin de solutionner le problème :
- Bien vérifier dans les options serveur que l'option est sur "demander" ou "télécharger automatiquement".
- Vérifier que le mod Optifine est bien lancé.
- Purger le dossier "server-resource-packs" dans votre dossier personnel .minecraft

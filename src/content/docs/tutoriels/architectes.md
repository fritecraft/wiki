Commandes utiles à la construction de donjons et d'aventures.
## Mode Créatif
Les vicaires ont la possibilité (même le besoin) d'utiliser le mode créatif pour les constructions dans le monde Bouquenia.
Pour activer le mode créatif, plusieurs commandes équivalentes :
  /vicaire
  /gmc
  /creative
Pour revenir en mode survie :
  /survie
  /gms
L'utilisation de certaines commandes de WorldEdit sont également possible pour ceux qui savent les utiliser :
  /br
  /biome
  /sel
  /fixwater /fixlava et /drain
  /replacenear
  Sur le serveur, l'outil de sélection est le bâton de blaze.
L'utilisation du plugin de Têtes de Décoration (HeadDatabase) :
  /headdb, /hdb, /heads pour ouvrir le menu
  /hdb search
L'inventaire du mode Créatif est séparé de l'inventaire Survie. Toutes les modifications sont loggées. Certaines commandes liées à l'économie sont désactivées en mode Créatif. Les interactions avec les entités et les conteneurs sont bloqués. Certains blocs ne sont pas disponible en mode Créatif (Command Blocs, spawners, bedrock).
## Loots
### Coffre de loot de donjon
Les loots de donjon doivent servir de récompense de progression dans les donjons, et ne doivent pas être nécessairement cachés. Ils doivent récompenser l'exploration des joueurs.
- Placer une tête correspondante au donjon
- Cibler la tête. Attention aux blocs transparent comme l'eau ou les barrières.
- /loot link Donjon

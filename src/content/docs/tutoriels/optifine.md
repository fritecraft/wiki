## C'est quoi ?
https://optifine.net/home
Optifine est un mod pour Minecraft, qui a pour but de modifier les graphismes du jeu.
Historiquement, le mod avait simplement pour but d'optimiser le code de rendu graphique du jeu, et permettait donc de gagner souvent pas mal de FPS et réduire les pics de lag.
Puis, petit à petit, le mod a ajouté d'autres fonctions pour modifier le rendu et le rendre plus beau : Textures HD, assemblages de textures, Shaders, lumières dynamiques, textures d'items ...
Fritecraft supporte pleinement ce mod ; il est même nécessaire de l'installation afin de profiter de certaines fonctions du serveur, notamment les textures uniques.
## Installation
L'installation d'Optifine est très facile.
- Lancez votre jeu au moins une première fois (arriver sur le menu principal, pas l'écran de login), puis fermez le. Cette étape sert juste à télécharger les ressources officielles depuis les serveurs Mojang. Si vous avez déjà joué à la version actuelle, vous pouvez sauter cette étape.
- Rendez-vous sur la page officielle du mod (et pas un forum ou site de mods qui pourraient vous fournir une version non-légitime du mod) : https://optifine.net/downloads
- Vous pouvez soit utiliser le bouton "download", qui vous affichera une publicité pour supporter l'auteur du mode, ou sur "mirror", pour ne pas avoir de publicité.
- Vous devriez vous retrouver avec un fichier avec l'extension ".jar" dans votre dossier téléchargements. Il s'agit d'un exécutable, il est donc nécessaire de l'exécuter avec Java
- Si vous n'avez pas Java sur votre PC : https://www.java.com/en/download/
- Attention à bien EXECUTER le fichier, pas extraire ou autre.
- Une fenêtre doit alors s'ouvrir, qui vous propose d'installation Optifine. En un clic, le profil est installé.
- Lancez le client minecraft : en bas à gauche, vous devriez voir que le profil Optifine est sélectionné.
